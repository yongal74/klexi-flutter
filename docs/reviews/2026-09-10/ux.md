# Klexi UI/UX review — 2026-09-10 (원문, v1.0.6+52). Paths relative to `lib/`.

1. **P1 — Settings "Start Free Trial" buys nothing.** `features/settings/presentation/settings_screen.dart:480` — `onPressed: () => Navigator.of(context).pop()`. User taps the orange CTA, sheet closes, nothing happens. Card (368-444) is also shown to paying users. Fix: replace `_PremiumSheet` with `context.push(AppRoutes.premium)`; hide card when `isPremiumProvider` is true. Confidence: high.

2. **P1 — Paywall dead-ends when RevenueCat offerings fail.** `features/premium/presentation/premium_screen.dart:91-99` passes `null` prices on error → `_PlanCard` (385-391) shows spinners forever; button reads "then …/yr". `:43` surfaces raw `$e`. Fix: error branch renders "Couldn't load prices — Retry" and disables Subscribe; map errors to friendly text. (Restore Purchases 258-262 and 7-day-annual-only wording 221/247 are correct and match Terms.) Confidence: high.

3. **P1 — Pronunciation/TTS failures are invisible or misleading.** `features/pronunciation/presentation/pronunciation_screen.dart:68-73` never clears `_loading` when session is empty → infinite spinner. `core/services/pronunciation_service.dart:39-45` returns score 0 offline → user sees a red **0** ring (screen 265-276) as if they failed. Mic permission denied → snackbar in Korean (`:116`). `core/utils/tts_service.dart:96-99,127-130` swallow errors then fall back to device TTS with no Korean-voice check → tap speaker, silence. Fix: empty state + "Complete a session first"; treat `score==0 && transcript.isEmpty` as error banner; English string; toast on TTS failure. Confidence: high.

4. **P1 — Korean UI text shown to English learners.** `features/word_network/presentation/word_network_screen.dart:503` `'더 보기 (300)' / '간략히 (150)'` (free feature, prominent button); `features/chat/presentation/dalli_chat_screen.dart:240` timeout message in Korean; pronunciation `:116`. Fix: move to `AppStrings` ("Show more (300)", "Response timed out…"). Confidence: high.

5. **P1 — Guest has no upgrade path; progress is lost.** `core/services/auth_service.dart:152` `upgradeGuestWithGoogle()` is never called anywhere. The only route is Sign Out (`settings_screen.dart:209-229`) → Google, which uses a new Hive box (`study_records_<uid>`), so streak/words vanish. No screen says "Sign in to save progress". Fix: in `_ProfileCard` show "Sign in with Google to back up progress" for `isGuest`, wired to `upgradeGuestWithGoogle`. Confidence: high.

6. **P1 — Dead settings controls (confirmed).** `settings_screen.dart:57-75`: both switches only `setState` local fields; "Daily Reminders" always shows ON regardless of `notif_enabled`; "Slow TTS Speed" `_slowTts` is read nowhere — `TtsService.speak` (`tts_service.dart:34-38`) only gets `TtsSpeed.slow` from the hardcoded call in `sentence_card_screen.dart:303`. `:99` "App Version 1.0.0" vs pubspec 1.0.6. Fix: remove the duplicate reminder switch (keep `notification_settings_screen.dart`); persist slow-TTS in a Riverpod provider read by `TtsService`; use `package_info_plus`. Confidence: high.

7. **P1 — No onboarding.** `core/constants/app_strings.dart:14-23` defines onboarding copy but no screen/route uses it; router (`core/router/app_router.dart:61-67`) goes auth→home. New user lands on Home with 6 unlabeled quick actions and a TOPIK selector with no explanation. Auth screen "Continue as Guest" is `Colors.grey` (`auth_screen.dart:100`), privacy note `grey.shade400` 11px (`:105`). Fix: 3-page PageView using existing strings, shown once via SharedPreferences. Confidence: high.

8. **P1 — Session completion is inconsistent / dead-ends.** `daily_session_screen.dart:66-81` "All done — come back tomorrow" has no CTA, while `sentence_card_screen.dart:152-159` offers "Next 20 →" (which re-pushes the same day's IDs — likely repeats words). Learn tab (`learn_screen.dart:94`) still says "Continue". Fix: one completion component offering Quiz / Practice / Review. Confidence: medium-high.

9. **P1 — Quiz integrity.** `quiz_screen.dart:84-98` distractors come only from session words → 2-3 options if session is small, or duplicate English meanings ("to be slow" appears at levels 1/2/3). `cloze_quiz_screen.dart:31-36` samples all 7,200 words ignoring premium/level → free users get TOPIK-6 items. `quiz_screen.dart:69`, `pronunciation_screen.dart:60`, `sentence_practice_screen.dart:57` call `getTodayWordIds()` without `isPremium/userLevel` unlike `daily_session_screen.dart:34` → different word sets across modes. Fix: pad distractors from the same level, dedupe by English; pass level args. Confidence: high.

10. **P2 — Four different paywall presentations.** Home/Learn locks push `/premium` directly (`home_screen.dart:258`, `learn_screen.dart:204,282`), `PaywallGate` renders a full placeholder screen, Word Network shows a dark dialog (`word_network_screen.dart:345-379`), Settings shows the dead sheet. Fix: single `showPaywall(context, feature)` helper. Confidence: high.

11. **P2 — Dalli chat polish.** "Online" dot always green (`dalli_chat_screen.dart:431-442`); error replies are persisted into history (239-254) so a stale "Connection error" becomes Dalli's headline next launch; back arrow is a bare 20px `GestureDetector` (368-371). No AppBar → `SystemUiOverlayStyle.dark` from `app_theme.dart:37-39` persists → dark status icons on #0D0E1A; same for Word Network's transparent AppBar (`:558-561`) on #080A18. Fix: wrap with `AnnotatedRegion(SystemUiOverlayStyle.light)`; don't persist error messages. Confidence: high.

12. **P2 — Contrast.** `textMuted` #9CA3AF on white ≈ 2.5:1 for 11-13px text (`settings_screen.dart:606`, `learn_screen.dart:254`, inactive nav labels `main_scaffold.dart:101`); primary #667EEA with white ≈ 3.9:1 (fails AA for 14-16px button labels, `paywall_gate.dart:92-101`). Fix: muted → #6B7280 for text ≤13px; darken primary buttons to #5A6FD6 or use 18px+ labels. Confidence: high.

13. **P2 — Touch targets under 48dp.** Home level chips ≈30dp (`home_screen.dart:346`), Word Network chips ≈26dp (`:937`) and close icon 20px (`:1027-1029`), Dalli mode chips (`:409`), level-words TTS 36dp (`level_words_screen.dart:416`), grammar/theme level chips ≈29dp. Fix: `minimumSize`/`SizedBox(height:44)` wrappers. Confidence: high.

14. **P2 — Overflow risks.** `word_card_screen.dart:90-98` unbounded `Row` of three chips; category "Basic Adverbs & Particles" + "adjective" + "TOPIK 1" exceeds 360dp → RenderFlex overflow. `level_words_screen.dart:215-220` header line wraps inside a fixed 160px flexible space. `learn_screen.dart:306-324` title `Row` with "Pro" badge lacks `Expanded`. Fix: `Wrap`, `maxLines`, `Flexible`. Confidence: medium-high.

15. **P2 — Accessibility & dark mode.** Icon-only buttons have no `tooltip`/`Semantics` (`sentence_card_screen.dart:267-304`, `level_words_screen.dart:411-417`, Dalli send `:567`; the only tooltip is `word_network_screen.dart:580`); most cards are `GestureDetector`, not buttons, for TalkBack. `app_theme.dart:148` `dark => light` and `main.dart:59-64` passes no `darkTheme`, so system dark is ignored (acceptable, but Settings/Progress hardcode `Colors.white`/hex, so a future dark theme needs rework). Edge-to-edge otherwise OK: nav bar uses `SafeArea(top:false)` (`main_scaffold.dart:37`), bottom paddings present in cloze/hangeul/premium/word panel. Confidence: high.

**Biggest conversion/retention risks:**
1. Two of the four premium entry points either do nothing (#1) or spin forever on network hiccups (#2) — direct lost purchases.
2. Guests (the default trial cohort) have no way to keep their streak when they convert to Google/premium (#5), and no onboarding tells them what to do first (#7).
3. Pro features that fail silently or in Korean (#3, #4) make the paid tier look broken right after purchase.
