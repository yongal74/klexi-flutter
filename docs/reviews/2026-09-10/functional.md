# Klexi functional-completeness audit — 2026-09-10 (원문)

Server routes registered: `/api/health`, `/api/ai-chat`, `/api/ai-tts`, `/api/pronunciation/score` (`functions/src/index.ts:28-34`). `polar.ts` is never imported/registered.

## (A) Broken in production — ranked

1. **Premium TTS (CLOVA/Google) never works — routes don't exist.** Client: `lib/core/utils/tts_service.dart:81` POSTs `/api/tts/clova` ({text,voice,speed,pitch}); `:113` POSTs `/api/tts/google` ({text,voice,speakingRate}). Server only has `/api/ai-tts` expecting `{text, voice: OpenAI voice}` (`functions/src/ai-tts.ts:12-14`). Every call 404s → caught at `:96/:127`, logged to Crashlytics, falls back to device TTS. Additionally most callers never pass `isPremium` (`sentence_card_screen.dart:270,302`, `level_words_screen.dart:310`, `pronunciation_screen.dart:150`) so the server path isn't even attempted, while `word_card_screen.dart:46` and `sentence_practice_screen.dart:118` pass `isPremium: true` unconditionally (free users too). User sees: robotic device voice always; Settings strings "Naver CLOVA / Google Neural2" (`app_strings.dart:127-128`) are fiction. Fix: point client at `/api/ai-tts` with `{text, voice:'nova'}` or add the two routes; gate on real `isPremiumProvider`. Confidence: high.

2. **Study data is not per-uid; migration and account deletion touch the wrong Hive box.** Writer: `daily_session_service.dart:88,97` opens box `study_records` (shared). `auth_service.dart:163-181` migrates `study_records_<guest>` → `study_records_<uid>` (boxes that never exist → no-op), and `deleteAccount` `:138-144` deletes `study_records_<uid>` — leaving all study history on disk after "Delete Account" (Play compliance claim in commit 38cdcf2 is not met). Also two Google accounts on one device share progress. Fix: name the box by uid in `DailySessionService.init(uid)` and reopen on auth change. Confidence: high.

3. **Session never restored on restart.** `restoreSession()` (`auth_service.dart:28`) has zero callers; `currentUserProvider` starts null (`:199`) and router `initialLocation: /auth` (`app_router.dart:61`). Every cold start shows the login screen even though Firebase persists the user. Fix: call `restoreSession()` in `main.dart` before `runApp` and seed the provider. Confidence: high.

4. **Web build (Firebase Hosting root) is a blank shell.** `firebase_options.dart:19-21` throws for web (caught in `main.dart:22-32`), but `PurchaseService.instance.initialize()` (`main.dart:43`) → `Purchases.configure` (`purchase_service.dart:38`) is outside any try/catch and `purchases_flutter` has no web implementation → `main()` aborts before `runApp`. `pronunciation_service.dart:4` and `pronunciation_screen.dart:1` also import `dart:io`. `build/web` is what `firebase.json:3` deploys. Fix: guard `!kIsWeb` around purchases/FCM, or replace hosting root with a landing page and keep only `/privacy`, `/terms`, `/delete-account`, `/api/**`. Confidence: high.

5. **Theme pack → Word Card always shows the wrong word.** `theme_detail_screen.dart:79` pushes `/word-card?id=theme-kdrama-1-1`; `word_card_screen.dart:27-29` searches `WordRepository.getAllWords()` (ids like `1-1`) with `orElse: words.first` → every theme word opens the first TOPIK-1 word. Fix: look up `getThemeWords()` first. Confidence: high.

6. **Cloze quiz leaks premium levels and ignores gating.** `cloze_quiz_screen.dart:31-36` picks 10 random words from all 7,200 with no `isPremiumProvider` check; route `/cloze-quiz` has no PaywallGate (`app_router.dart:128-131`). Free users get L2–6 words; results are not persisted (no `recordStudy`). Confidence: high.

7. **Settings toggles are inert.** `settings_screen.dart:63-64` "Slow TTS Speed" and `:73-74` "Daily Reminders" are local `setState` only — never persisted, never read by `TtsService`/`NotificationService`. App Version hardcoded `'1.0.0'` (`:99`) vs pubspec `1.0.6+52`. Confidence: high.

8. **Pronunciation offline fallback shows score 0 as a real result.** `pronunciation_service.dart:39-45` returns `score: 0` on any Dio error; screen renders `_ScoreCard` with 0 (`pronunciation_screen.dart:265-270`) — a timeout (server 30s Whisper vs `receiveTimeout` 30s at `:111`) looks like "you failed". Field names/paths otherwise match (`/api/pronunciation/score`, multipart `audio`+`text`, `pronunciation.ts:63-68`). Confidence: medium-high.

9. **`assets/images/` and `assets/icons/` declared in `pubspec.yaml:85-86` do not exist** (only `assets/fonts/`, `icon-512.png`). (PM 정정: 이 Flutter 버전에선 경고에 그치고 빌드는 성공함.) Confidence: medium.

## (B) Incomplete / misleading

1. **Notifications**: `scheduleDailyReminder` is only called from `notification_settings_screen.dart:45` on screen pop. No first-run scheduling; users who never open that screen get nothing. The `notif_enabled` default `true` (`:29`) is a lie until saved.
2. **FCM is a dead end**: token saved to prefs (`fcm_service.dart:69-72`), `getSavedToken`/`consumePendingRoute`/`subscribeToTopic` have no callers; `functions/src` contains no `admin.messaging` / scheduled sender. No server push exists.
3. **Settings `_PremiumSheet` "Start Free Trial"** (`settings_screen.dart:480-496`) just `Navigator.pop` — never reaches `/premium`. "App Version" tile `onTap: () {}` (`:105`).
4. **Premium pitch vs reality**: "Advanced progress analytics" (`premium_screen.dart:176`) — `progress_screen.dart` has no premium branch. "Full Word Network exploration" — free users can already see level-1 graph; only level switch gated (`word_network_screen.dart:332-338`). "7,200 TOPIK words" is accurate (6×1,200 verified).
5. **Gating map**: PaywallGate: `/dalli-chat`, `/grammar(/:id)`, `/themes(/:id)`, `/pronunciation`. Inline `isPremium`: level selector/grid, `/level/:level` (`level_words_screen.dart:96`), daily session/sentence card/quiz/review/practice (`w.level == 1` filter). Ungated: `/cloze-quiz` (leak, A6), `/word-card?id=<any level>` (browsable for free), `/word-network` level-1 only, `/hangeul`. Note `sentence_card?level=N` route (`app_router.dart:112-120`) has no level check — only reachable via gated screens today.
6. **Progress screen is internally consistent** (reads same `lastStudied/timesStudied/easyCount/hardCount` keys it writes, `daily_session_service.dart:198-210` vs `:118-128`), but "Words Learned" = any word touched once (`getTotalWordsStudied` = box key count), streak counts a day only via `lastStudied` (re-studying a word erases its earlier day from `getWeekActivity`/streak, `:241-246, :310-312`).
7. **Chat**: SSE format matches (`data: {content}` / `{done:true}`, `ai-chat.ts:88-89,146,156` vs `dalli_chat_screen.dart:207-214`), but `_history` (`:145`) is in-memory only — persisted UI history is reloaded (`:112-126`) while the model gets no context after restart. Server `{error}` events are silently ignored (`:214` treats as empty content).
8. **Backend is fully unauthenticated** (no ID-token check in any route; `index.ts:36 invoker: public`) — OpenAI cost exposure; CORS list only affects browsers.
9. **Content wiring is real**: grammar 108 patterns, 6 themes × 600 words, 360 sentence groups, 48 theme sentences (`theme_sentences.dart`) — but `theme_sentences.dart` has no screen consumer (grep: only defined). Hangeul: 10 consonants + 8 vowels, no scoring — pure free-draw canvas (`hangeul_tracing_screen.dart:15-37, 182-196`).
10. **Dead code**: `functions/src/polar.ts` (never registered; `POLAR_*` env unused), `polar_service.dart` re-export, `srs_algorithm.dart`, `WordRepository.getDailyWords`.
